# Anticipation Consulting — brand assets

Identity assets for social profiles and outward-facing use, built from the two
brand typefaces. Everything in `dist/` is generated by `generate_assets.py`, so
the kit is reproducible and stays consistent with the website.

![preview](dist/_preview.png)

## Mission, voice & values

**Mission** — *We find questions you didn't know to ask and deliver evidence
designed to be challenged.*

**Tagline** (the short lockup used on banners) — *What you didn't know to ask.*
It's the first clause of the mission; the full mission is reserved for prose, as
it's too long for a tracked lockup.

**Voice** — direct, understated, precise, intellectually honest. Plain strong
nouns and verbs, em-dashes for rhythm; no hype ("leverage", "cutting-edge",
"empower"). **Values:** honesty over confidence, reproducible by default,
documented for scrutiny, independent judgment. **Content rule:** no fabricated
clients, logos, metrics, or outcomes — ever.

See [`AGENTS.md`](../AGENTS.md) for the full project, design, and brand context.

## Network background

Banner-sized stills of the live interactive background (`#net-bg` in
`assets/site.js`) — triangle nodes in the logo triad joined by gradient links
that fade with distance. The generator ports the canvas algorithm exactly
(node density, link radius, opacities, triangle geometry), seeded so the layout
is reproducible. Each size ships on two grounds: warm **paper** (what visitors
see on the site) and **ink** (for dark social headers and slides).

## Site assets (generated straight into the site)

Two artifacts the **website** serves are generated here as well, so this script
is their single source of truth — they can't fall out of step with the identity
the way a hand-maintained copy did (the old OG image went stale through three
redesigns because nothing regenerated it).

| File | What it is | Generated by |
| --- | --- | --- |
| `../images/og-image.png` | 1200×630 Open Graph / social card — wordmark + tagline on the ink network | `og_card()` |
| `../assets/favicon.svg` | the mark as a baked outline (ink ground, no web-font dependency) | `write_favicon()` |

`check_assets.py` regenerates everything into a throwaway tree and fails if any
committed asset — `dist/*`, the OG image, or the favicon — has drifted from the
generator (SVGs compared exactly; PNGs within a perceptual tolerance; the OG
image's dimensions cross-checked against `og:image:width/height` in
`_includes/head.html`). It runs in CI on every push and pull request.

## Typefaces

- **GFS Didot** — the "A" mark. SIL Open Font License.
- **Cormorant Garamond** — the wordmark. SIL Open Font License.
- **IBM Plex Mono** — the tagline lockup. SIL Open Font License.

Fonts are not vendored in the repo; `fetch_fonts.sh` pulls them from Google
Fonts. Generated raster/vector output is unrestricted.

## Clearspace & usage

- Keep clearspace around the mark of at least the height of the **A**.
- Don't recolor the mark outside the palette, rotate it further, or stretch it.
- On busy photography, use `avatar-ink-*` or place the mark on a solid ground.

## Regenerating

```bash
cd brand
./fetch_fonts.sh                       # once, fetches OFL fonts into fonts/
pip install Pillow fonttools           # cairosvg optional, only to validate SVGs
python3 generate_assets.py             # writes dist/ + the site's og-image & favicon
python3 check_assets.py                # verify nothing drifted (also runs in CI)
```

Edit the palette/spacing constants at the top of `generate_assets.py` to adjust.
After editing, **re-run `generate_assets.py` and commit** — CI fails if the
committed images no longer match the generator.
